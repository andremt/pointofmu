Match reasoning and match flaw ask you to abstract an argument's *structure* away from its subject matter, then find the answer choice with the same structure. Content similarity is a deliberate trap, an answer choice about the same topic as the stimulus is, if anything, more likely to be wrong than right, because the test writers know that's where your attention will drift.

## Fast filters, run in this order

**1. Match the conclusion type first.** Before reading closely, classify the stimulus's conclusion: conditional, causal, comparative, predictive, or a value judgment. Then eliminate any answer choice whose conclusion is a different type, cheap, fast, and it typically clears out two or three of the five answers before you've read them carefully at all.

**2. Match the flaw** (on match-flaw specifically). Name the flaw in the stimulus in your own words first, the way you would on a plain flaw question, then scan the remaining answers for the one committing the same error, not the same topic, the same *mistake*.

**3. Match the logical form** only if two answers survive the first two filters. This means checking the actual chain of reasoning step by step: how many premises, how they connect, whether the argument commits the same specific logical move (e.g., affirming the consequent, treating a necessary condition as sufficient) in the same place.

## A timing note worth internalizing

These are consistently among the longest questions in the Logical Reasoning section, five full argument stimuli have to be read, not just five short answer choices. If two answers survive both the conclusion-type and flaw filters and time is tight, guessing between the finalists and moving on is often the correct call: the expected value of a third careful read is usually lower than the value of the next question you haven't touched yet.
